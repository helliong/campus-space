# CampusSpace — Система бронирования учебных пространств университета

Проект: Веб-платформа бронирования аудиторий, коворкингов и лабораторий.


2. Система бронирования учебных пространств «CampusSpace»
В корпусах университета сотни аудиторий, переговорных, коворкингов и компьютерных классов. Студентам и преподавателям сложно найти свободное помещение под проектную встречу, подготовку к экзамену или внеурочное занятие.
Сервис должен обеспечивать:
Каталог помещений с фото, вместимостью, оснащением (проектор, маркерная доска, ПК и т. д.), условиями доступа.
Интерактивный календарь занятости с бронированием на слоты от 30 минут до полного дня.
Согласование бронирований: автоматическое для свободных слотов, с одобрением администратора для специализированных помещений.
Личный кабинет: история бронирований, текущие брони, управление рекуррентными бронированиями.
Систему рейтингов и отзывов о помещениях (чистота, оснащение, комфорт).
Уведомления о статусе заявок, напоминания о предстоящих бронированиях.
Ключевой сценарий: Карта кампуса / список помещений → Фильтрация по оснащению и вместимости → Календарь слотов → Бронирование → Подтверждение → Личный кабинет с активными бронированиями.

## Структура проекта

```text
campus-space/
├── frontend/              # Next.js 15, React, TypeScript, Tailwind
│   └── src/
│       ├── app/           # App Router и страницы
│       ├── components/    # UI-kit и общие layout-компоненты
│       ├── features/      # auth, bookings, campus-map, spaces
│       └── lib/           # API-клиент и общие утилиты
├── backend/               # FastAPI, SQLAlchemy, Pydantic, Celery
│   ├── app/
│   │   ├── api/           # REST endpoints
│   │   ├── core/          # конфигурация и безопасность
│   │   ├── db/            # подключение к PostgreSQL
│   │   ├── models/        # SQLAlchemy-модели
│   │   ├── schemas/       # Pydantic-схемы
│   │   ├── services/      # бизнес-логика
│   │   └── tasks/         # фоновые задачи
│   ├── migrations/        # Alembic
│   └── tests/
├── docker/                # Dockerfiles, Compose и init PostgreSQL
└── docs/                  # продуктовая и техническая документация
```

## Локальный запуск

1. Скопировать `.env.example` в `.env`.
2. Выполнить `docker compose -f docker/docker-compose.yml --env-file .env up --build`.
3. Frontend: <http://localhost:3000>, API: <http://localhost:8000/docs>.
